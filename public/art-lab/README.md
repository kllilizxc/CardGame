# 烬羽 EMBERWING · 像素生命实验场

纯 HTML + Canvas 2D 的独立修仙像素美术验证场。无素材下载、无第三方运行依赖。

## 运行

在项目根目录执行 `bun run dev-nolog`，打开 **http://localhost:8080/art-lab/index.html**。
必须包含 `index.html`；Vite 会把 `/art-lab/` 回退到游戏主入口。
也可以直接用浏览器打开本目录 `index.html`，保留同目录的 `lifecycle.js` 即可。
生产构建会将整个目录复制到 `dist/art-lab/`。

## 内容

- 30 秒、10 阶段：唤灵 → 凝形 → 栖焰 → 巡游 → 蓄势 → 焚天 → 受创 → 陨落 → 余烬 → 涅槃。
- 羽片分层着色、双翼骨架、十二尾翎的延迟摆动、羽冠、眨眼、呼吸、爪部动作。
- 环绕火流、羽刃、冲击环、逆向聚气、固定种子爆发粒子、羽片解体、残影、辉光、受击顿帧、镜头震动。
- 月夜山水、松枝、远寺、雾、萤火、石质浮岛、动态火盆、符阵、水纹与角色倒影。
- 四套配色，六个合成图层，0–200% 粒子密度，场景 / 透明底 / 特写模式。
- 时间轴任意定位、0.25–2 倍速、1/60 秒逐帧、十阶段缩略图、全屏、点击散落余烬。

`Space` 播放/暂停；`← / →` 逐帧；`R` 重播；`A` 蓄力；`H` 受击；`B` 重生；`G` 网格；`F` 全屏。

## 导出

- **当前帧 PNG**：1920×1080，最近邻 3 倍放大；透明底模式导出真正透明的 PNG。
- **动作图集**：单个 ZIP，包含 2048×1920 透明 PNG 和 JSON 元数据。每阶段一行、八个采样帧，每格 256×192；JSON 提供时间、状态和帧区域。图集包含当前开启的角色特效图层，关闭符阵/粒子/辉光可以取得更干净的角色帧。
- **WebM**：以当前视觉配置从 0 秒开始录完整 30 秒轮回，完成后自动保存并恢复录制前的播放状态。录制时保持前台；切到后台或手动停止会保存已录片段。录制使用浏览器 MediaRecorder，需支持 WebM 的 Chrome/Edge 等浏览器。无音轨。

## 实现与验证

`lifecycle.js` 是与浏览器无关的确定性状态/姿态模型；`index.html` 包含像素渲染与交互。角色、粒子和解体直接由时间及种子求值，定位到任意帧无需重新积累模拟。点击粒子使用独立时钟，不进入 PNG/图集导出。

原生画布为 640×360，CSS 使用最近邻缩放。场景静态部分缓存，动态部分每帧重画。像素几何在整数网格绘制，辉光采用低分辨率径向渐变。动效为程序化美术样机，尚未接入 Phaser 战斗系统。

测试：`bun test tools/art-lab/lifecycle.test.js`。

## 风格变体：听雨 · 法术练功场

打开 **http://localhost:8080/art-lab/storm.html**。这是参考用户提供的「法术练功场」静态海报而独立实现的风格研究，不包含原作代码或图片素材。此版本为单文件 HTML，可直接离线打开。

- 300×320 实际显示画布（600×640 逻辑绘图，最近邻降采样；导出最近邻 4 倍放大）：冷紫雨夜、月亮与旋转星涡、遗迹石柱、像素抖色、湿石倒影、雨幕和水花。
- 四种独立法术：流火符、九霄引雷、霜莲封印、星陨之门。包括凝气、出手、弹道、命中、余韵，和稻草人受击、散开、重塑。
- 自动轮播，也可选择法术后点画面或按 Space 施放；1–4 切换、P 暂停、右方向键逐帧。暂停时施法会提示继续播放。
- 支持雨幕、辉光、震动、抖色、音效开关及粒子强度；音效默认为关，需要主动开启。柔和模式关闭震动与辉光并降低粒子数量。
- PNG 导出为 1200×1280 最近邻放大图像；可全屏预览。
- 已在浏览器验证四法术各自只结算一次命中、重复输入冷却、过期效果回收、3000 生命靶身归零后恢复及 60 秒轮播。

强化版：角色放大、阶梯色块光照、火焰大爆破、三重雷柱、大型冰晶、陨星星芒和飞石；命中加入 75 ms 停顿与更强回弹。
